\subsection{题目描述}

在欧氏平面上给定一个顶点按照逆时针顺序给出的多边形 $P = P_0P_1 \cdots P_{n-1}$。

记一个角度 $\alpha$ ($0 \le \alpha < \frac{\pi}{2}$) 为一个\BF{稳定方向}，当且仅当存在 $c \in \R$，使得对于多边形 $P$ （含边界）内的任意一点 $X$ 到直线 
\[
	\cos \alpha\,x + \sin \alpha\,y + c = 0
\]
的垂线段完全包含在 $P$ （含边界）内。


请求出满足条件的 $\alpha$ 的数量，可以证明\BF{稳定方向}只有有限个。

\subsection{输入格式}

第一行输入一个整数 $T$ ($1 \le T \le 100$)，表示测试数据的数量。

每组测试数据第一行输入一个整数 $n$ ($3 \le n \le 10^5$)，表示多边形的顶点数量。

随后 $n$ 行，每行输入两个整数 $x_i, y_i$ ($-10^9 \le x_i, y_i \le 10^9$)，表示多边形的第 $i$ 个顶点的坐标，按逆时针顺序给出。

保证多边形是简单多边形（边不相交），且所有测试数据的 $\sum n \le 10^5$。

\subsection{输出格式}

对于每组测试数据，输出一行一个整数，表示满足条件的\BF{稳定方向}的数量。
