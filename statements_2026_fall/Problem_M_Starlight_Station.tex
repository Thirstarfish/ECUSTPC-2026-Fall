\subsection{题目描述}

你拿着的三叉戟再次击中了村民，但这一次，当审判结束，你却发现自己已经找不到它了。

据你所知，你的三叉戟落在一棵有 $n$ 个结点以 $1$ 号结点为根的有根树 $T$。每个结点都有一个权值 $a_i$，并且任意时刻所有结点的权值都恰好构成 $1 \sim n$ 的一个排列。对于树上的两个结点 $u,v$，记它们之间的简单路径为 $P(u,v)$，注意此处 $u , v \in P(u, v)$。

定义一个树上结点集合 $S$ 为一个\textbf{三叉}，当且仅当存在三个结点 $F$，$x$，$y$，满足：

\begin{itemize}
	\item $F$ 是 $x$ 的祖先或 $F=x$；
	\item $F$ 是 $y$ 的祖先或 $F=y$；
	\item $S = P(F,x)\cup P(F,y)$；
	% \item 注意此处 $x = y$ 满足条件。
\end{itemize}


你需要按顺序处理 $q$ 次操作，操作共有三种：

\textbf{操作 1：引雷}，给定两个结点 $x$ 和 $y$，交换它们当前的权值。

\textbf{操作 2：审判}，给定两个不同的权值 $l$ 和 $r$，记 $a_u = l$, $a_v = r$，并且令 $F = \text{LCA}(u, v)$，$k = a_F$，此处的 $k$ 可以和 $u$ 或 $v$ 相等，$\text{LCA}$ 表示最近公共祖先。

将 $l, r, k$ 从小到大排序，得到 $s_1 \le s_2 \le s_3$ 且多重集合 $\{s_1, s_2, s_3\} = \{l, r, k\}$。
随后对所有的权值进行如下的变化，设操作前结点 $x$ 的权值为 $a_x$，操作后为 $a_x'$。

此时定义
\[
a'_x=
\begin{cases}
a_x+(s_3-s_2+1), & s_1\le a_x<s_2,\\
s_1+s_3-a_x, & s_2\le a_x\le s_3,\\
a_x, & \text{otherwise}.
\end{cases}
\]

随后对所有 $1 \le x \le n$ 的整数 $x$，同时令 $a_x \leftarrow a'_x$，可以证明操作前后序列始终是 $1 \sim n$ 的一个排列

\textbf{操作 3：寻戟}，给定 $l \le r$，判断 $S=\{x \in \N, 1\le x \le n \mid l\le a_x\le r\}$ 是否是一个\textbf{三叉}。

请依次回答所有\textbf{操作 3：寻戟}所提出的问题。

\subsection{输入格式}

第一行输入一个整数 $T$ ($1 \le T \le 10^3$)，表示测试数据的数量。

每组测试数据第一行输入两个整数 $n$ 和 $q$ ($1 \le n, q \le 10^5$)，表示树上的结点数量和操作的数量。

随后 $n - 1$ 行每行输入两个整数 $u$ 和 $v$ ($1 \le u, v \le n$, $u \ne v$)，表示树上存在一条连接 $u$ 和 $v$ 的边。

随后一行输入 $n$ 个整数 $a_1, a_2, \ldots, a_n$ ($1 \le a_i \le n$)，表示每个结点的权值。

随后 $q$ 行每行表示一次操作，第 $i$ 行首先输入一个整数 $\text{op}_i$ ($1 \le op_i \le 3$)，表示操作类型，随后格式如下：

\begin{itemize}
	\item 若 $\text{op}_i = 1$，随后输入两个整数 $x$ 和 $y$ ($1 \le x, y \le n$)，表示进行一次\textbf{操作 1：引雷}，交换 $x$ 和 $y$ 的权值。
	\item 若 $\text{op}_i = 2$，随后输入两个整数 $l$ 和 $r$ ($1 \le l < r \le n$)，表示进行一次\textbf{操作 2：审判}，对权值再 $[l,r]$ 之间的结点权值做变换。
	\item 若 $\text{op}_i = 3$，随后输入两个整数 $x$ 和 $y$ ($1 \le l \le r \le n$)，表示进行一次\textbf{操作 3：寻戟}，查询权值在 $[l,r]$ 之间的点是否构成一个\textbf{三叉}。
\end{itemize}

保证单组测试数据内，所有结点的权值构成 $1\sim n$ 的一个排列，给定的边形成一棵 $n$ 个结点的树。

保证所有测试数据的 $\sum n \le 3 \times 10^5$，$\sum q \le 3 \times 10^5$。

\subsection{输出格式}

对于每组测试数据中指令类型为\textbf{操作 3：寻戟}的指令输出一行一个字符串：

\begin{itemize}
	\item 若$S=\{x \in \N \mid l\le a_x\le r\}$ 是一个\textbf{三叉}，则输出 \TT{YES}；
	\item 反之则输出 \TT{NO}。
\end{itemize}

注意评测时不会区分 \TT{YES} 和 \TT{NO} 的大小写，换言之当答案是肯定的时候输出 \TT{yes}、\TT{YES}、\TT{Yes}、\TT{YeS} 等都会被认为是正确的。

对于第 $1$ 组测试数据的第三次寻戟，经过前一次审判操作后，当前各结点的权值为$(a_1,a_2,\ldots,a_7)=(4,6,2,5,7,3,1)$。

此时权值 $4,5,6,7$ 分别位于结点 $1, 4, 2, 5$，因此 $S=\{1,2,4,5\}$。

取 $F = 1$，$x = 4$，$y = 5$，依次验证条件：

\begin{itemize}
	\item 结点 $1$ 是结点 $4$ 的祖先。
	\item 结点 $1$ 是结点 $5$ 的祖先。
	\item $P(1,4)\cup P(1,5) = \{1,2,4\} \cup \{1,2,5\} = S$。
\end{itemize}

因此 $S$ 是一个\textbf{三叉}。
