\begin{problem}{一分为二}{standard input}{standard output}{3 second}{256 megabytes}

\textit{别在昨天的回忆里频频回首，说什么将寂寞对半分担。}

给定一个长度为 $n$ 的正整数数组 $a$。你需要判断是否存在该数组的一个子序列，使得这个子序列中所有元素的和恰好等于原数组所有元素之和的一半。

数组 $a$ 的子序列是指：从 $a$ 中删除零个或多个元素后，不改变剩余元素相对顺序所形成的新序列。


\InputFile
每个测试文件包含多组测试用例。

第一行包含一个整数 $t$ ($1 \le t \le 1000$) ------ 测试用例的数量。

每个测试用例的第一行包含一个整数 $n$ ($1 \le n \le 5000$) ------ 数组 $a$ 的长度。

每个测试用例的第二行包含 $n$ 个整数 $a_1, a_2, \dots, a_n$ ($1 \le a_i \le n$) ------ 数组 $a$ 的元素。

保证所有测试用例中 $n$ 的总和不超过 $5000$。

\OutputFile
对于每个测试用例，如果存在满足条件的子序列，输出 YES；否则输出 NO。

你可以以任何大小写形式输出答案（例如，yEs、yes、Yes 和 YES 均会被视为肯定回答）。


\end{problem}
