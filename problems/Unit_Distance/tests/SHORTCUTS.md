# 简单构造实验

当前整数输出题面下，`shortcut_grid.cpp` 是一个能通过所有合法 n 的替代解。

令 w=ceil(sqrt(n))，按行输出前 n 个格点，r=i/w，c=i%w：

- n<100：X=c*10^13+r*5*10^12，Y=r*8660254037844，近似三角网格。
- n>=100：X=c*2*10^12，Y=r*2*10^12，间距 1/5 的正方形网格。

后者中，格点位移 (±5,0)、(0,±5)、(±3,±4)、(±4,±3) 对应单位距离，内部点度数为 12。

固定使用上述按行布局和 w，计数结果：

| 方案 | 首次失败 n | n=5000 的单位距离对数 |
|---|---:|---:|
| 间距 1 的直线 | 16 | 4999 |
| 间距 1 的正方形网格 | 43 | 9858 |
| 三角网格 | 170 | 14718 |
| 间距 1/5 的正方形网格 | 6 | 27357 |
| 小于 100 用三角网格，其余用 1/5 网格 | 无 | 27357 |

n=5000 的要求为 25719 对。

运行 `python tests/test_shortcuts.py` 可复现实验。脚本先按网格位移精确计数比较五种方案，再编译并调用 `audit_shortcut.cpp`：逐点对用 128 位整数验证混合方案在全部 4999 个合法 n 上的坐标范围、最小距离与单位距离对数。每个 n 的要求用 Python 大整数独立计算。最后编译正式 checker 和 generator，执行 script.txt 中全部 29 组生成命令。

本次结果：4999/4999 个规模通过精确检查，29/29 个生成文件通过正式 checker。该构造本身合法，不是浮点容差或 checker 漏洞；不能通过在现有范围内补输入数据卡掉它。
